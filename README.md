# Вебпортал новин інституту 📰

Курсовий проєкт: сучасний адаптивний вебпортал новин та лендинг для університету. Next.js, TypeScript, Tailwind CSS. Основний акцент зроблено на UI/UX.

A modern, responsive news portal and landing page for a university institute. Course project built with Next.js, TypeScript, and Tailwind CSS, with a focus on UI/UX.
