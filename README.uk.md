# Вебпортал новин інституту

Сучасний, адаптивний вебпортал новин та інформаційний лендинг для університету/інституту. Проєкт розроблено в межах курсової роботи з фокусом на **UI/UX дизайн**, зручність користування (Usability) та сучасний вигляд інтерфейсу.

---

## 📌 Про проєкт & UX/UI Концепція

Основна мета цього проєкту — оновити застарілий інтерфейс новинної сторінки університету та зробити його зручним, інтуїтивним і привабливим для студентів, абітурієнтів і викладачів.

### Дизайнерські рішення (Figma):
* **Аналіз кращих практик:** Перед розробкою було проведено дослідження вебсайтів провідних світових університетів та популярних новинних медіаресурсів.
* **Фокус на UX:** Зручна навігація, чітка ієрархія контенту, швидкий доступ до важливих розділів (академічна мобільність, спеціальності, пошук).
* **Сучасний UI:** Чистий вигляд, приємне колірне оформлення, увага до типографіки, мікроінтерактивності та адаптивності для мобільних пристроїв.

> **Примітка:** Проєкт є демонстраційною фронтенд-платформою. Дані новин зберігаються локально (JSON), без використання повноцінної серверної CMS.

---

## Основний функціонал та фічі

- **Головна сторінка (Landing):** Інформація про напрями підготовки (спеціальності), програму академічної мобільності та дайджест свіжих новин.
- **Сторінка новин:** Відображення головної новини (Hero-article), можливість сортування за датою публікації та зручна пагінація.
- **Пошуковий модуль:** Швидкий пошук за заголовками та текстом новин із підтрикою пагінації результатів.
- **Детальний перегляд:** Сторінка окремої новини з повним текстом, зображеннями та сторінка викладачів/адміністрації інституту.
- **Мультимовність (i18n):** Вбудований перемикач мов (українська / англійська).
- **Адаптивність:** Повноцінне мобільне меню та оптимізація під будь-які розміри екранів.

## 🛠️ Технологічний стек

* **Фреймворк:** [Next.js](https://nextjs.org/) (App Router)
* **Мова програмування:** [TypeScript](https://www.typescriptlang.org/)
* **Стилізація:** [Tailwind CSS](https://tailwindcss.com/)
* **Локалізація:** Власна логіка / мовні конфігурації
* **Джерело даних:** Локальні JSON-файли

## 📁 Структура проєкту

```text
├── public/
│   ├── images/              # Зображення та логотипи
│   └── newsimages/          # Зображення новин
└── src/
    ├── app/                 # Сторінки та логіка застосунку (App Router)
    │   ├── page.tsx              # Головна сторінка
    │   ├── news/
    │   │   ├── page.tsx          # Список новин
    │   │   └── [id]/page.tsx     # Окрема новина
    │   ├── search/page.tsx       # Пошук
    │   ├── teachers/page.tsx     # Адміністрація
    │   ├── api/news/route.ts     # API новин
    │   ├── layout.tsx
    │   ├── globals.css
    │   └── actions.ts
    ├── components/          # Компоненти інтерфейсу
    │   ├── home/                 # Секції головної сторінки
    │   ├── layout/               # Шапка, меню, футер, пошук, перемикач мови, хлібні крихти
    │   └── news/                 # Картки новин, сортування та пагінація
    ├── data/                # Дані новин, навігації, головної та адміністрації
    └── lib/                 # Локалізація, форматування дат, пагінація
```
